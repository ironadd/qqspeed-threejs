# QQ飞车 · 极速漂移（Three.js 网页卡丁车）

在线试玩：https://ironadd.github.io/qqspeed-threejs/ （手机横屏，点 ⛶ 全屏效果更佳）

一个参考 QQ飞车 / 跑跑卡丁车风格的 3D 卡丁车网页游戏，用 Three.js 写成，**单个 HTML 文件**，不用任何外部素材，断网也能玩。

## 赛道
- **阳光都市**（日，默认）：明亮的白天城市，长直道 + 直角弯 + 发卡弯 + 大弯 + 极速隧道
- **霓虹黄昏**：黄昏霓虹城市，路灯光斑、霓虹招牌、车头灯
- **雪域森林**：雪地森林里的流线型高速赛道

## 玩法
- 漂移积攒氮气，最多储存 2 个；松开漂移触发小喷
- 氮气加速、加速带、道具箱（导弹 / 香蕉皮 / 护盾）
- 5 个 AI 对手，3 圈比赛、倒计时起步加速、实时排名、小地图、最佳单圈记录
- 音效全部用 WebAudio 实时合成：引擎声、漂移声、氮气声、背景音乐等

## 操作
- 手机：自动油门，左下 ◀ ▶ 转向，右下 漂移 / 氮气 / 道具 / 刹车
- 键盘：←→/AD 转向，Shift 漂移，空格 氮气，E 道具，↓/S 刹车，P 暂停

## 开发
源码在 `game.js` 和 `shell.html`，运行 `node build.js` 会把 `three.min.js` 和游戏代码合成到 `index.html`（也就是 `qqspeed.html`）。
